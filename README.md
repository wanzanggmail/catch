# CATCH — 캣치

브라우저용 2D 수직 스크롤 플랫포머 프로토타입.

## 실행

```bash
npm install
npm run dev
```

## 조작

| 동작 | 키보드 | 터치 |
|------|--------|------|
| 이동 | A/D 또는 ←/→ | 가상 D-Pad |
| 점프 (홀드 시 높이 가변) | Space / ↑ | 점프 버튼 |
| 공격 | Z / J | 공격 버튼 |
| 가방 버프 사용 | X / K | 아이템 버튼 |

## 구성

- Phaser 3 + TypeScript + Vite
- 세이브 슬롯 3개 (localStorage)
- 스테이지 6 × 맵 5 = 30개 기본 맵 (슬롯별 진행으로 90 세션)
- 진화 3단계, 지형 기믹, 거대 쥐 보스
